`invoice.xlsx` contains a draft invoice (sheet **Invoice**). The VAT rate is in cell **B1**. Each line item already has its **Net** amount; the **VAT** and **Gross** columns are empty.

Fill in, for every line item:

- **VAT** = Net × the VAT rate in B1
- **Gross** = Net + VAT

Use formulas, so that changing the rate in B1 updates every line and the totals. The **Total** row at the bottom must show the correct Net, VAT and Gross totals.
